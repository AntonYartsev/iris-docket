Audit chain verifier

Drop a journal export from Docket's Audit screen. This page re-computes every digest and says whether the chain holds - offline, with no account on the instance and no way to ask it anything. It is a static file: save it, take it somewhere else, and it reaches the same answer.

How the digest is computed

Each entry is hashed together with the digest of the one before it, so altering a record, removing one or slipping one in changes every digest after it. The recipe, which this page implements in about thirty lines and anything with a SHA-256 can implement in as few: 

record    = the entry without its prevHash and hash fields
canonical = JSON of record, keys sorted, no whitespace  (args stays the stored string)
hash      = base64( sha256( utf8( prevHash + canonical ) ) )

A file that starts at sequence 1 with an empty prevHash carries its own beginning. A file that starts later is a slice: the entries in it can still be shown unaltered and consecutive, but nothing in it can say what happened before the first one.
